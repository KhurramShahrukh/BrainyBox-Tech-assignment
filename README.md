# Vite + React + TypeScript + Tailwind CSS

## Steps to run project locally
1. Download repository.
2. Use lts Node version.
3. Open terminal and run the following command "npm install".
4. After isnalling the nde modules, run "npm run dev".
5. Now you will be able to see the project running on the local host on the port mentioned in your terminal.
